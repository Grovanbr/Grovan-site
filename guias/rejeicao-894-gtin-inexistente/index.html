Rejeição 894: GTIN inexistente no Cadastro Centralizado de GTIN

O código de barras (GTIN/EAN) do produto na nota não existe no cadastro nacional de códigos de barras. Veja por que acontece e como corrigir em poucos minutos.

O que significa

O código de barras (GTIN/EAN) do produto na nota não existe no cadastro nacional de códigos de barras.

Por que acontece

  • O código de barras foi digitado errado.
  • O produto usa um código interno ou de outra embalagem, que não é um GTIN válido registrado.
  • O fabricante não registrou aquele código.

Como resolver

  1. Confira o código de barras na embalagem do produto e corrija o campo GTIN/EAN no cadastro.
  2. Se o produto não tem código de barras válido, preencha os campos GTIN e GTIN tributável com SEM GTIN.
  3. Reenvie a nota.

Este guia é uma orientação geral. Para dúvidas de tributação (CST, CFOP, alíquotas), confirme com a sua contabilidade.

Perguntas frequentes

Posso inventar um código de barras?

Não. Só vale GTIN registrado. Sem código válido, use SEM GTIN.

O GTIN tributável é diferente do GTIN?

Pode ser. O tributável é o da unidade usada no cálculo do imposto, por exemplo a unidade dentro de uma caixa com 12.
